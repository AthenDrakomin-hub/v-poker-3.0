## 二、意识流一：横屏"重力场"视觉美学

### 2.1 视觉重力梯度（三层结构）

- **黄金三角区**（牌桌中央）：绝对视觉重心，底池数字定制衬线字体，只显数字无单位
- **暗角消隐区**（四周边缘）：Vignette羽化遮罩，聊天框/功能键半透明悬浮，永不遮挡牌面
- **前置手牌区**：最高Z轴层级，投影悬浮效果，暗示玩家控制权

### 2.2 设计规范

| 元素 | 规范 |
|------|------|
| 底池数字 | Didot/Trajan类衬线体，字重Light，字间距-2px，只显数字 |
| 底池容器 | 毛玻璃圆角胶囊，背景透明度15%，边框1px金色渐变 |
| Vignette遮罩 | 径向渐变，中心透明→边缘rgba(0,0,0,0.7)，羽化半径60% |
| 聊天框 | 左下角悬浮，宽25%屏宽，高30%屏高，毛玻璃背景 |
| 手牌Z轴 | Z-index=100（全场最高），box-shadow: 0 8px 24px rgba(0,0,0,0.5) |

## 三、意识流二：牌局情绪"蒙太奇"时间流

### 3.1 三种时间切片

#### 发牌期（序曲）
- 每张牌0.3秒，多张依次延迟80ms
- Ease-Out曲线，微抛物线轨迹
- 0.3秒延迟是多巴胺预留时间

#### 行动期（博弈）
- 呼吸光晕频率90bpm（人类紧张心率）
- opacity 0.3→0.8→0.3，box-shadow 0→12px→0
- 禁用border闪烁，只用光晕呼吸

#### 摊牌期（高潮）
- 子弹时间滤镜：四周暗化，唯独赢家牌面高光
- 1.2秒：0.3s暗化 + 0.6s高光 + 0.3s恢复
- 编钟余韵音效（80Hz，混响2秒）
- 向内的狂喜比向外的喧哗更高级

## 四、意识流三：V3抽水分配"鎏金仪式"可视化

### 4.1 倒金字塔鎏金动画

```
塔尖：抽水总额30筹码
  ↓ 金色流体流下
塔身2/3处分流
  ↓ 三条流体
开房代理10 | 上级代理5 | 平台10
```

### 4.2 动画时序

| 时间 | 动作 | 时长 |
|------|------|------|
| T+0 | 底池数字升起化为金色光球 | 0.4s |
| T+0.4 | 光球到塔尖 | 0.3s |
| T+0.7 | 流体流下分流 | 0.5s |
| T+1.2 | 注入三容器，数字滚动 | 0.6s |
| T+1.8 | 守恒等式"30=10+5+5+10"浮出 | 0.3s |
| T+4.0 | 墨迹隐入背景 | 1.0s |

### 4.3 视觉规范

- 金色流体：线性渐变#FFD700→#FFA500→#FF8C00，drop-shadow发光
- 流体粒子：50-80个金色粒子，2-4px，带拖尾
- 守恒等式：极淡书法字体，rgba(255,215,0,0.6)，14px
- 墨迹隐入：从边缘模糊扩散消失

## 六、五座斗兽场：游戏主题设计

### 6.1 《紫禁之巅·斗兽场》—— 抢庄牛牛
- 主色调：黑金#1A1A1A + #FFD700
- 牌桌纹理：黑色丝绒+蛛网裂纹
- 粒子效果：倒计时焚香粒子
- 开牌高潮：金光炸裂+破屏金光
- 注意：焚香粒子层级低于抢庄按钮

### 6.2 《江南百景·青玉案》—— 抢庄三公
- 主色调：月白天青#E8F4F8 + #4A90A4
- 牌桌纹理：水波纹涟漪
- 粒子效果：落叶粒子
- 开牌高潮：水面涟漪+水墨晕染
- 注意：动画时长0.2-0.25秒，避免影响连局

### 6.3 《机械迷城·流水线》—— 通比牛牛
- 主色调：蒸汽朋克#2D2D2D + #CD7F32铜色
- 牌桌纹理：金属铆钉+齿轮纹理
- 粒子效果：蒸汽粒子
- 开牌高潮：机械臂冲压+震屏（幅度≤3px）
- 注意：震屏幅度自适应限制

### 6.4 《雾都夜话·黑胶密房》—— 炸金花
- 主色调：暗夜黑胶#0A0A0A + #FFD700聚光
- 牌桌纹理：黑色绒布+聚光灯
- 看牌动作：毒蛇吐信般微滑
- 开牌高潮：聚光灯收窄+黑胶唱针咔嗒
- 注意：背景黑色用平滑Gradient避免灰阶断层

### 6.5 《华尔街之狼·信息交易所》—— 德州扑克
- 主色调：金融冷峻#0F1923 + #00D4FF青色
- 牌桌纹理：半透明玻璃+微弱K线图
- 发牌仪式：三段式发牌（翻牌/转牌/河牌）
- 开牌高潮：公共牌网格线亮起+资金划转
- 注意：网格线呼吸光效不干扰牌面识别

## 七、API对接设计

### 7.1 认证流程
- 登录 → 获取Token → 本地存储 → 后续请求携带
- Token存储：uni.setStorageSync('vpoker_token', token)
- 请求头：Authorization: Bearer <token> 或 x-vpoker-token: <token>

### 7.2 WebSocket对接
- 进入房间 → 建立Socket连接（携带Token）
- 事件：join_room / room_update / hand_update / chat_message / state_changed

## 八、技术实现要点

### 8.1 横屏适配
- 设计基准：1920×1080（16:9）
- 单位：rpx
- 安全区：env(safe-area-inset-*)

### 8.2 性能优化
- 动画使用transform和opacity
- 粒子数量≤100，Canvas渲染
- 长列表虚拟滚动
- 离开房间页销毁Socket/定时器/粒子系统

### 8.3 音效系统
- 发牌声0.1秒 / 筹码声0.15秒 / 编钟余韵80Hz混响2秒
- 心跳声90bpm极淡 / 环境音循环音量<10%
